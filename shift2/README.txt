gpt-shift シフト表 PWA

GitHub Pages への設置
1. ZIPを展開し、shift2 フォルダごとリポジトリの公開元フォルダにアップロードします。
2. 既存の GitHub Pages が main ブランチの /(root) を公開している場合、shift2 は既存の shift と同じ階層に置きます。
3. 公開後、GitHub Pages のアドレスの末尾に shift2/ を付けて開きます。

データの移行
元のアプリで「保存/読込」→「保存」から JSON を端末に保存します。
新しいアプリで「保存/読込」→「読込」を選び、その JSON を読み込みます。
スタッフ名やシフトを含む JSON は端末で扱い、公開リポジトリにアップロードしないでください。

ホーム画面への追加
公開ページを Chrome で開き、「ホーム画面に追加」を押します。
